## 一、项目概述

### 1. 项目背景
传统高校选课依赖人工登记、Excel管理，效率低、易出错、数据难以共享。本项目基于课程实践需求开发学生选课管理系统，面向高校日常选课、教学管理场景，实现选课流程数字化，简化教务工作，提升数据管理规范性与安全性，具备较强教学实践与实际应用价值。

### 2. 项目目标
1. 实现学生、教师、管理员三类角色的完整选课业务流程；
2. 完成选课、退课、课程管理、成绩管理、用户管理等核心功能；
3. 系统稳定易用，操作简洁，满足小型教务场景使用需求；
4. 完成系统开发、测试、部署全流程，形成可交付的完整项目成果。

### 3. 开发环境与条件
- 开发工具：IntelliJ IDEA、VS Code、Navicat
- 后端技术：Java + Maven + Spring Boot
- 数据库：MySQL 8.0
- 版本控制：Git + GitHub
- 运行环境：JDK 1.8+、Windows/Linux

---

## 二、需求分析

### 1. 目标用户与使用场景
- 学生：在线查看课程、选课、退课、查询个人成绩；
- 教师：管理授课课程、录入与修改学生成绩；
- 管理员：管理用户信息、课程信息、系统权限与数据维护。

### 2. 核心功能清单
1. 用户登录与权限管理
2. 学生选课、退课功能
3. 课程信息展示与查询
4. 教师成绩录入与管理
5. 学生信息、课程信息管理
6. 系统数据查询与统计

### 3. 非功能需求
- 性能要求：页面响应快，支持多用户同时在线操作；
- 安全要求：不同角色权限隔离，密码安全验证，防止越权访问；
- 兼容性要求：支持主流浏览器访问，系统运行稳定。

---

## 三、技术路线

### 1. 总体架构
采用 B/S 架构，前后端分离模式：
- 前端负责页面展示与交互
- 后端提供接口服务与业务逻辑
- 数据库负责数据存储

### 2. 主要技术
- 前端：HTML、CSS、JavaScript、Vue/Axios
- 后端：Java、Spring Boot、Maven
- 数据库：MySQL
- 工具：Git、IDEA、Navicat

### 3. 数据设计初步考虑
- 主要实体：学生、教师、管理员、课程、选课记录、成绩记录
- 关键数据表：用户表、课程表、选课表、成绩表
- 关系：学生与课程多对多，教师与课程一对多

| 测试不充分，结项时出现严重bug | 每个模块开发完成后立即自测，中期后安排一轮完整功能测试，预留修改时间 |

- 远端Git仓库地址：`https://github.com/wE2for/student_system`
