# 用户手册
项目名称：学生选课管理系统
小组序号：49
编写人员：李杭
编写日期：2026年5月19日

## 一、系统简介
学生选课管理系统用于高校学生在线选课、教师管理成绩、管理员维护数据，实现教务管理数字化。

## 二、运行环境
- 浏览器：Chrome / Edge
- 网络：局域网/本机
- 后端：SpringBoot 已启动
- 数据库：MySQL 8.0

## 三、学生使用指南
1. 打开系统登录页
2. 输入用户名、密码，选择【学生】角色登录
3. 进入学生首页
4. 点击【课程信息】浏览课程
5. 点击【选课】完成选课
6. 点击【选课信息】查看已选课程
7. 可执行【退课】操作
8. 点击【成绩查询】查看个人成绩
9. 可修改个人密码

## 四、教师使用指南
1. 用户名密码登录，选择【教师】角色
2. 进入教师页面
3. 查看授课课程信息
4. 查看选课学生名单
5. 对学生进行成绩录入与修改
6. 可修改个人密码

## 五、管理员使用指南
1. 管理员账号登录
2. 功能菜单：
   - 管理员信息管理
   - 教师信息管理
   - 学生信息管理
   - 学院信息管理
   - 专业信息管理
   - 课程信息管理
   - 选课信息管理
3. 支持：新增、编辑、删除、查询、分页
4. 权限最高，可管理全部数据

## 六、注意事项
1. 请牢记账号密码
2. 请勿重复选课
3. 退课需在选课期内进行
4. 不同角色权限不同，不可越权操作
5. 若页面异常，刷新或重新登录即可

## 七、常见问题
Q：无法登录？
A：检查账号、密码、角色是否选择正确。

Q：选课失败？
A：可能已选过该课程或课程人数已满。

Q：页面显示错乱？
A：更换Chrome/Edge浏览器，刷新重试。
