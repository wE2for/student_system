| 阶段任务 | 计划内容 | 实际完成情况 | 完成度 |
| ---- | ---- | ---- | ---- |
| 需求与架构设计 | 需求文档、ER图、系统架构设计 | 已完成，并根据开发微调表结构 |中|
| 开发环境搭建 | 前后端环境、Git仓库、协作规范 | 已完成，分支与提交规范落地 |中|
| 后端核心接口 | 登录、权限、课程、选课/退课 | 全部完成，接口可正常调用 |良|
| 前端页面开发 | 登录、课程列表、选课页面 | 主体完成，样式与交互待优化 |中|

### 2.2 已实现核心功能
1. **多角色登录与权限控制**
   实现学生、教师、管理员三类角色登录，权限隔离，不同角色展示对应功能菜单。
2. **课程信息管理**
   管理员可对课程进行增删改查，学生可浏览可选课程列表。
3. **学生选课与退课**
   支持选课、退课操作，包含基础重复选课校验。
4. **数据持久化**
   MySQL数据库稳定，用户、课程、选课记录可正常增删改查。

团队每日提交代码，定期合并，无大规模冲突，版本管理规范。

## 三、存在问题与改进措施

### 3.1 主要问题
1. 前后端接口文档不够细致，联调时出现参数不匹配
2. 部分细节功能未完善：分页、实时人数校验、成绩管理模块未完成
3. 测试覆盖不足，异常场景测试较少
4. 前端样式与交互体验有待优化

### 3.2 改进方案
1. 统一接口文档，明确参数、返回值、状态码
2. 优先完成成绩管理、用户管理等结项必需功能
3. 建立测试用例，对异常流程进行专项测试
4. 优化页面布局与响应式展示，提升使用体验
