# 测试计划文档
项目名称：学生选课管理系统
小组序号：49
编写人员：王志杰、李杭
编写日期：2026年5月

## 一、测试目标
确保学生选课管理系统功能完整、流程正确、权限合理、数据一致，满足课程设计验收标准。
保证登录、选课、退课、成绩管理、用户管理、权限控制等核心功能稳定运行。

## 二、测试范围
1. 用户登录模块（学生/教师/管理员）
2. 课程管理模块
3. 选课与退课模块
4. 学生信息管理模块
5. 教师成绩录入模块
6. 管理员权限模块
7. 前后端接口与数据库交互

## 三、测试策略
- 黑盒测试：验证输入输出、业务流程是否符合需求
- 功能覆盖测试：覆盖所有核心操作路径
- 接口测试：验证后端接口可用性与数据正确性
- 兼容性测试：主流浏览器页面展示与操作

## 四、测试环境
- 操作系统：Windows 11
- 浏览器：Edge、Chrome
- 开发工具：IDEA、VS Code
- 后端：SpringBoot
- 数据库：MySQL 8.0
- 测试工具：Postman、浏览器开发者工具、Navicat

## 五、人员分工
- 王志杰：测试用例执行、接口测试、BUG记录
- 李杭：前端页面测试、流程验证、文档整理
- 胡宇豪：后端支持、数据库验证
- 刘乐意：测试统筹、结果确认

## 六、测试进度安排
1. 测试计划编写：1天
2. 测试用例设计：1天
3. 功能测试执行：2天
4. 测试结果汇总：1天
5. 问题修复与回归测试：1天

## 七、风险与应对
1. 页面显示异常 → 检查CSS、浏览器兼容性
2. 接口请求失败 → 检查后端服务、URL、参数
3. 数据不同步 → 核对数据库字段与业务逻辑
4. 权限控制失效 → 重新验证角色拦截规则
