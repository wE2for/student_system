# 需求分析文档
项目名称：学生选课管理系统
小 组 号：49
编写人员：李杭
编写日期：2026年5月15日

## 一、项目概述
### 1.1 项目背景
传统高校选课工作多依赖人工登记、Excel 表格管理，存在效率低下、易出错、数据难以共享、统计困难等问题。为满足课程实践教学要求，同时解决实际教务管理痛点，本次开发学生选课管理系统，实现选课流程数字化、规范化，提升教务管理效率与数据安全性，具备教学实践与实际应用双重价值。

### 1.2 项目目标
1. 实现学生、教师、管理员三类角色的完整选课业务流程。
2. 完成选课、退课、课程管理、成绩管理、用户管理等核心功能。
3. 系统界面简洁易用、运行稳定，满足小型高校教务场景使用需求。
4. 完成从开发、测试到部署的完整流程，形成可交付、可演示的项目成果。

### 1.3 开发环境
- 开发工具：IntelliJ IDEA、VS Code、Navicat
- 后端技术：Java + Maven + Spring Boot
- 数据库：MySQL 8.0
- 版本控制：Git + GitHub
- 运行环境：JDK 1.8+、Windows/Linux

---

## 二、目标用户与使用场景
### 2.1 学生用户
- 在线查看课程信息与课程介绍
- 进行选课、退课操作
- 查询个人选课结果与已选课程
- 查询个人课程成绩

### 2.2 教师用户
- 管理个人授课课程信息
- 对选课学生进行成绩录入与修改
- 查看选课学生名单

### 2.3 管理员用户
- 管理学生、教师账号信息
- 维护课程信息、添加/编辑/删除课程
- 进行系统权限分配与数据维护
- 对系统数据进行查询与简单统计

---

## 三、核心功能需求
### 3.1 用户登录与权限管理
- 支持学生、教师、管理员三种角色登录
- 不同角色展示不同菜单与操作权限
- 实现账号密码验证，防止非法登录
- 权限隔离，禁止越权访问其他角色功能

### 3.2 学生选课与退课
- 展示所有可选课程列表
- 学生可进行选课与退课操作
- 限制重复选课、课程容量控制
- 实时更新选课状态

### 3.3 课程信息管理
- 课程信息展示、查询、筛选
- 管理员可新增、修改、删除课程
- 记录课程名称、学分、学时、授课教师、上课时间等信息

### 3.4 成绩管理
- 教师可对授课课程下的学生录入成绩
- 教师可修改已录入成绩
- 学生可查询本人各科成绩
- 成绩数据持久化存储

### 3.5 用户信息管理
- 管理员管理学生、教师基本信息
- 支持信息新增、编辑、删除、查询
- 统一维护账号体系

### 3.6 系统数据查询与统计
- 支持按学生、课程、教师多维度查询
- 支持选课人数、成绩情况等简单统计展示
- 为教务管理提供数据支撑

---

## 四、非功能需求
### 4.1 性能需求
- 页面响应迅速，操作无明显延迟
- 支持多用户同时在线进行选课、查询操作
- 数据库查询高效，无明显卡顿

### 4.2 安全需求
- 不同角色严格权限隔离
- 登录密码验证，防止非法访问
- 防止越权操作、SQL 注入等常见安全问题
- 数据存储安全可靠，不易丢失

### 4.3 兼容性需求
- 支持 Chrome、Edge 等主流浏览器访问
- 页面具备一定响应式能力
- 系统在 Windows 环境下可稳定运行

---

## 五、数据需求初步分析
### 5.1 主要实体
- 学生
- 教师
- 管理员
- 课程
- 选课记录
- 成绩记录

### 5.2 主要数据表设计方向
- 用户表（存储学生、教师、管理员信息）
- 课程表（课程基本信息）
- 选课表（学生选课关系）
- 成绩表（学生课程成绩）

### 5.3 实体关系
- 学生与课程：多对多关系（一个学生可选多门课，一门课可被多个学生选）
- 教师与课程：一对多关系（一个教师可教多门课）
