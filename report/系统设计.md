# 一、引言
## 1.1 文档目的
本文档为学生选课管理系统的系统设计说明书，用于明确系统架构、功能模块划分、数据库设计、前后端交互流程及技术实现方案，指导项目开发、测试与验收工作。

## 1.2 项目背景
传统高校选课依赖人工登记、Excel管理，效率低、易出错、数据难以共享。
本项目基于课程实践需求开发学生选课管理系统，实现选课流程数字化，简化教务工作，提升数据管理规范性与安全性。

## 1.3 开发环境
- 开发工具：IntelliJ IDEA、VS Code、Navicat
- 后端技术：Java + Maven + Spring Boot
- 数据库：MySQL 8.0
- 版本控制：Git + GitHub
- 运行环境：JDK 1.8+、Windows

# 二、系统总体架构设计
## 2.1 整体架构
本系统采用 **B/S 架构 + 前后端分离模式**。
- 前端：负责页面展示、用户交互、数据请求
- 后端：提供接口服务、业务逻辑处理、数据校验
- 数据库：负责数据持久化存储

## 2.2 系统分层
1. **表现层**：HTML/CSS/JavaScript 页面
2. **请求层**：Axios 发送异步请求
3. **控制层**：后端 Controller 接收请求
4. **业务层**：Service 处理核心逻辑
5. **数据访问层**：DAO 操作数据库
6. **数据层**：MySQL 存储数据

## 2.3 技术选型
- 前端：HTML、CSS、JavaScript、Axios
- 后端：Java、Spring Boot、Maven
- 数据库：MySQL 8.0
- 工具：Git、GitHub、IDEA、Navicat

# 三、功能模块设计
系统分为 **公共模块、学生模块、教师模块、管理员模块** 四大模块。

## 3.1 公共模块
- 用户登录与身份验证
- 权限拦截与页面跳转
- 全局布局与样式统一

## 3.2 学生模块
- 课程信息浏览与查询
- 在线选课与退课
- 个人选课记录查看
- 个人成绩查询

## 3.3 教师模块
- 授课课程管理
- 学生成绩录入与修改
- 选课学生名单查看

## 3.4 管理员模块
- 学生信息管理（增删改查）
- 教师信息管理
- 课程信息管理
- 选课记录管理
- 系统数据维护

---

# 四、数据库设计
## 4.1 主要数据表
- 用户表（user_info）
- 课程表（course_info）
- 选课表（selection_info）
- 成绩表（score_info）
- 学院表、专业表

## 4.2 实体关系
- 学生 ↔ 课程：多对多
- 教师 ↔ 课程：一对多
- 课程 ↔ 成绩：一对多

## 4.3 核心字段说明
- 用户表：用户ID、用户名、密码、角色、姓名
- 课程表：课程ID、课程名、学分、教师、容量
- 选课表：ID、学生ID、课程ID
- 成绩表：ID、学生ID、课程ID、成绩

## 5.2 主要页面

- 学生信息页面
- 教师信息页面
- 课程信息页面

## 5.3 前端交互
- 使用 Axios 请求后端接口

# 七、系统运行流程
1. 用户访问登录页面
2. 输入账号密码进行身份验证
3. 根据角色（学生/教师/管理员）进入对应页面
4. 前端通过 Axios 发送操作请求
5. 后端处理业务逻辑并操作数据库
6. 返回结果并在页面展示
7. 完成业务操作

---

# 八、安全设计
- 不同角色权限严格隔离
- 未登录用户禁止访问功能页面
- 后端接口权限校验
- 防止越权操作
- 密码安全验证
